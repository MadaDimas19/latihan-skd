# Latihan SKD CPNS 2026

Simulasi dan latihan soal SKD CPNS 2026 (TWK, TIU, TKP) dengan timer, penilaian otomatis, dan pembahasan.

- `index.html` : aplikasi kuis
- `bio.html` : halaman link untuk bio media sosial (isi tautan grup dan donasi di bagian `L` pada file ini)

## Catatan
Sarana latihan, bukan jaminan kelulusan. Tidak berafiliasi dengan BKN atau KemenPAN-RB. Selalu cek informasi resmi di SSCASN/BKN.
Progres belajar tersimpan di browser perangkat masing-masing.
